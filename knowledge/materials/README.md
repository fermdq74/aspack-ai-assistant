# Materiales de Cartón

Este directorio contiene documentación técnica sobre los distintos tipos de cartoncillo y cartón utilizados en el sector del embalaje.

## Tipos de materiales documentados

- **SBS (Solid Bleached Sulphate)** — Cartoncillo blanco de fibra virgen blanqueada
- **FBB (Folding Box Board)** — Cartoncillo de fibra virgen con núcleo mecánico
- **WLC (White Lined Chipboard)** — Cartoncillo de fibra reciclada con cubierta blanca
- **GD/GT grades** — Cartones reciclados grises
- **Kraft paperboard** — Cartón kraft de alta resistencia
