# Sostenibilidad

Este directorio contiene documentación sobre sostenibilidad, certificaciones forestales y economía circular en el sector del embalaje de cartón.

## Temas cubiertos

- **FSC y PEFC** — Certificaciones de gestión forestal sostenible
- **Huella de carbono** — Metodologías PCF, scopes 1/2/3, SBTi
- **ACV** — Análisis de Ciclo de Vida (ISO 14040/44)
- **DAP/EPD** — Declaraciones Ambientales de Producto (ISO 14025)
- **Reciclabilidad** — 4evergreen, RecyClass, INGEDE Method 11
- **Economía circular** — Contenido reciclado, eficiencia material, ecodiseño
- **Ecoetiquetas** — EU Ecolabel, Punto Verde, etiquetas de reciclaje
