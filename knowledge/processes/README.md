# Procesos de Fabricación

Este directorio contiene documentación sobre los procesos de fabricación y transformación de envases de cartón.

## Procesos cubiertos

- **Impresión offset** — Offset plano en hoja, convencional y UV
- **Flexografía** — Impresión flexográfica para tiradas largas
- **Impresión digital** — HP Indigo, Landa, inkjet para tiradas cortas
- **Troquelado** — Plano y rotativo, troqueles de acero
- **Pegado y encolado** — Máquinas folder-gluer, tipos de colas
- **Acabados** — Barnizado, plastificado, hot stamping, gofrado
