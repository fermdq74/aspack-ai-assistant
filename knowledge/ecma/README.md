# Estándares ECMA

Este directorio contiene documentación sobre los estándares de la European Carton Makers Association (ECMA) para envases de cartón plegable.

## Contenido

- **ECMA-A** — Cajas tuck-end (straight tuck, reverse tuck, auto-bottom)
- **ECMA-B** — Bandejas y fundas (sleeves)
- **ECMA-C** — Estilos especiales y misceláneos
- **Códigos ECMA** — Referencia de códigos estándar (ECMA-A20, A25, A50, etc.)
- **FEFCO** — Equivalentes para cartón ondulado
